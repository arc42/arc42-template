== 執行階段視圖


ifdef::arc42help[]
[role="arc42help"]
****
.內容
執行階段視圖以情境形式描述系統建構模組的具體行為與互動，涵蓋以下領域：

* 重要使用案例或功能：建構模組如何執行這些使用案例或功能？
* 關鍵外部介面的互動：建構模組如何與使用者及相鄰系統協作？
* 操作與管理：啟動、啟動程序、停止
* 錯誤與例外情境

備註：選擇可能情境（序列、工作流程）的主要標準是其 *架構相關性*。描述大量情境並不重要；您應記錄具代表性的選擇。

.動機
您應了解系統建構模組（實例）如何在執行階段完成工作並彼此通訊。
您主要在文件中記錄情境，以向較不願意或無法閱讀與理解靜態模型（建構模組視圖、部署視圖）的利害關係者傳達您的架構。

.形式
有許多描述情境的表示法，例如：

* 以自然語言撰寫的編號步驟清單
* 活動圖或流程圖
* 序列圖
* BPMN 或 EPC（事件流程鏈）
* 狀態機
* ...


.更多資訊

參見 arc42 文件中的 https://docs.arc42.org/section-6/[執行階段視圖]。

****
endif::arc42help[]
