[[section-architecture-constraints]]
== 架構限制

ifdef::arc42help[]
[role="arc42help"]
****
.內容
任何會限制軟體架構師在設計與實作決策，或開發流程決策上的自由度之要求。這些限制有時不只適用於個別系統，也適用於整個組織與公司。

.動機
架構師應清楚知道哪些設計決策可以自由決定，以及哪些地方必須遵守限制。
雖然有些限制可以通過協商討論，但限制始終都必須得到專注。

.形式
附有說明的簡單限制表格。
如有需要，您可以將其細分為技術限制、組織與政治限制，以及慣例（例如程式設計或版本控制指南、文件或命名慣例）。


.更多資訊

參見 arc42 文件中的 https://docs.arc42.org/section-2/[架構限制]。

****
endif::arc42help[]
