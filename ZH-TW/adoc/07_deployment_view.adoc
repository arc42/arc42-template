== 部署視圖

ifdef::arc42help[]
[role="arc42help"]
****
.內容
部署視圖描述：

1. 用來執行系統的技術基礎設施，包括地理位置、環境、電腦、處理器、通道、網路拓撲，以及其他基礎設施要素。
2. 將（軟體）建構模組對應至這些基礎設施要素。

系統通常會在不同環境中執行，例如開發環境、測試環境與生產環境。在這種情況下，您應記錄所有相關環境。

尤其當您的軟體以分散式系統的形式，在多台電腦、處理器、伺服器或容器上執行，或是當您設計與建構自己的硬體處理器和晶片時，更應記錄部署視圖。

從軟體角度來看，只需記錄足以呈現建構模組部署的基礎設施要素即可。硬體架構師則可以進一步依其所需的詳細程度描述基礎設施。

.動機
沒有硬體，軟體就無法執行。
這個底層基礎設施會影響系統和/或某些橫切概念。因此，有必要了解這些基礎設施。

.形式

最高層級的部署圖可能已經包含在第 3.2 節的技術脈絡中，並將您自己的基礎設施視為一個黑箱。在本節中，可以使用額外的部署圖深入說明這個黑箱：

* UML 提供部署圖來表達此視圖。當您的基礎設施較為複雜時，可以使用部署圖，可能還需要使用巢狀圖。
* 如果您的硬體利害關係人偏好其他類型的圖表，而不是部署圖，請讓他們使用任何能夠呈現基礎設施節點與通道的圖表。


.更多資訊

參見 arc42 文件中的 https://docs.arc42.org/section-7/[部署視圖]。

****
endif::arc42help[]

=== 基礎設施層級 1

ifdef::arc42help[]
[role="arc42help"]
****
描述（通常結合圖表、表格與文字）：

* 系統分佈至多個地點、環境、電腦、處理器等的位置，以及它們之間的實體連線
* 這種部署結構的重要理由或動機
* 此基礎設施的品質與/或效能特徵
* 將軟體產出物對應至此基礎設施的各項要素

如果有多個環境或替代部署，請為所有相關環境複製並調整 arc42 的此部分。
