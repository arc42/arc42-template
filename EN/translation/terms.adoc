= Translation terms: the English reference list
// This file is not part of the template: the arc42-generator never converts or publishes it.

the terms of the help texts and their recurring labels.

Every other language has a file `<LANG>/translation/terms.adoc` with these terms, the word its
translation uses for each of them and, where it helps, the reason for that choice.
When a term is added here, add it to the files of the other languages as well.
